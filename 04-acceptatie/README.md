# 4. Acceptatie

> Vereist hoofdstuk 1. Nog niet uitgewerkt.

Voegt de e2e gebruikersflow over de keten toe, op Acceptatie, met echte buren. De vraag is
of de keten doet wat een gebruiker verwacht. Contractverificatie maakt ketentesten niet
overbodig; het maakt ze kleiner en gerichter, omdat de structuur elders al is aangetoond
en de flow zich kan beperken tot wat een gebruiker daadwerkelijk doet.

Zie `docs/showcase-cbt.md`, hoofdstuk 4.
